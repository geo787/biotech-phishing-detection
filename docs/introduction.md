# Introduction

This project implements a hybrid phishing detection system combining Natural Language Processing (NLP) and the Berlekamp–Massey (BM) algorithm for URL complexity analysis. The system is designed with healthcare (Epic, Cerner, Medidata) and general business targets in mind.

This documentation accompanies the code and experimental artifacts in the repository. Use the table of contents in the project README to navigate chapters that explain background, methods, implementation details and ethical considerations.
